# KBR Restro & Bar - Restaurant Website

A modern, elegant, and fully responsive restaurant and bar website for **KBR Restro & Bar**, a premium Nepali restaurant and bar business in Kathmandu, Nepal.

## Overview

KBR Restro & Bar is a static front-end website showcasing authentic Nepali cuisine, premium bar services, and live entertainment. The website features a dark elegant theme with gold accents, smooth animations, and a modern responsive design.

## How to Run

### Direct Browser Access
1. Download or clone the project files
2. Open `index.html` in any modern web browser
3. No server required - it's fully static

### Local Server
```bash
# Using Python 3
python -m http.server 8000

# Then visit http://localhost:8000
```
